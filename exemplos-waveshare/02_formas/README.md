# 02_formas

Porte do `02_Shapes_on_Circular_Display`. Sobre fundo branco, desenha em sequência um quadrado, um triângulo e um círculo no centro, cada um com cor aleatória, um a cada 3 s, em loop.

```
mpremote run exemplos-waveshare/02_formas/02_formas.py
```

Usa `poly` e `ellipse` do `framebuf` (MicroPython 1.20 ou mais novo).

- **v1.0.0** - quadrado, triângulo e círculo com cores aleatórias a cada 3 s (ainda não testado na placa)
