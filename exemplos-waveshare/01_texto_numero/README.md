# 01_texto_numero

Porte do `01_Text_and_Number_Display`. Enche a tela de azul, vermelho e verde (1 s cada), depois mostra "Hello, Waveshare!" e um contador de 00 a 99 em números grandes, um por segundo.

Bom para conferir as cores: se o azul e o vermelho aparecerem trocados, o painel está em BGR.

```
mpremote run exemplos-waveshare/01_texto_numero/01_texto_numero.py
```
